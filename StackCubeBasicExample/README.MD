# StackCube Input Example

1. Build with `pio run -d StackCubeBasicExample` from the repository root.
2. Create `/games/InputExample` on the SD card. Copy [the manifest](sd/games/InputExample/.gameinfo) there, and copy `.pio/build/cores3/firmware.bin` from this project into that directory as `game.bin`.
3. Select **Input Example**. Move the dot with a mouse, arrow keys, D-pad, or stick. Esc or B returns to the launcher.
